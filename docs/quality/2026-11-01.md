# Quality check: 10 engineering rules (2026-11-01)

Scope: the Rego policies in `policy/`, their unit tests, and the shell scripts in `scripts/`. Run on
Windows 11 (Git Bash) with the pinned OPA 1.22.0 from `make setup`. The end-to-end check
(`make e2e`, Terraform plans with the AWS provider) and `make audit` (govulncheck) were not re-run
locally in this pass; CI runs both on every push.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Every call can fail | fixed | The only network calls are the tool downloads in `scripts/tools.sh`: `curl --retry 3` (curl backs off between attempts) but no time limit, so a stalled connection could hang `make setup`; now `--connect-timeout 20 --max-time 600`. Every script runs with `set -eu`; Terraform runs offline through `scripts/tf.sh` (allow-listed subcommands). The policies make no calls. |
| 2 | Writes safe to retry | pass | `tools.sh` downloads into a staging folder, verifies SHA-256 against the pin and the published sums, then installs; a rerun with the same stamp is a no-op. `mutate.sh` recreates `.tmp/mutants` each time. |
| 3 | No race conditions | N/A | Policies are pure functions of the plan JSON; scripts are sequential. |
| 4 | Don't trust the clock | N/A | No durations or timestamps in the policies or scripts. |
| 5 | Read before changing | pass | Environment variables set by `tf.sh` (`TF_CLI_CONFIG_FILE`, `TF_PLUGIN_CACHE_DIR`, `TF_DATA_DIR`, `TF_IN_AUTOMATION`, `TF_INPUT`, `CHECKPOINT_DISABLE`) are documented Terraform settings; `opa check --strict` rejects unknown built-ins and unused variables. |
| 6 | Never break compatibility | pass | Rule ids (PAC001-PAC006) and message formats are unchanged; the e2e check compares an exact expected-violations list. |
| 7 | One source of truth | pass | Tool versions and SHA-256 pins live only in `scripts/tools.sh`; README and results quote OPA 1.22.0, conftest 0.71.1, Terraform 1.17.1, the same values. The AWS provider is pinned by the committed lock files. |
| 8 | Small changes, no secrets, validate input | pass | No credentials anywhere (`tf.sh` clears AWS profiles, tokens and metadata and sets the obvious placeholder keys `offline-plan-placeholder`). `make check` refuses to run without `PLAN`; `tf.sh` refuses any subcommand outside its allow-list. |
| 9 | Tests that can fail | fixed | No skipped or tautological Rego tests (`grep -rn "todo\|skip" policy` empty). The existing 12 mutants were written by the author; 7 independent mutants were added to `scripts/mutate.sh`, one survived and is now killed. 18/19 before, 19/19 after. |
| 10 | Re-verify | pass | Results below; CI runs lint, test, mutate, e2e and audit. |
